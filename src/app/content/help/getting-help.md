Join the [Discord](https://discord.gg/PgH2gVZYKq) and say hello. Bug reports,
feature requests, and "is it meant to do this?" all welcome — come bug the dev.

When something's broken, the version number from **Settings → About** tells us
exactly which build you were on, which usually saves a round of questions.

Aura is free. If you'd like to help keep it running, there's a
[Ko-fi](https://ko-fi.com/Z8Z11OOHFX) link in the top bar.
